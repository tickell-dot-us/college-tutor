# Student Model

Live, versioned file for the course-tutor-coach skill. Updated (and committed) at the end of every coaching or maintenance session — see `skills/course-tutor-coach/SKILL.md` for the rules this file follows.

**Partitioned by subject on purpose.** Review sessions are subject-scoped, and keeping each subject's topics in its own section is what makes it hard to pull a cross-subject item by accident. Add a topic to its own subject's section; add a new section only when a course starts in a subject not listed here.

Mastery scale: **New** (not yet assessed) · **Shaky** (b/d errors present, <3 clean reps) · **Solid** (3+ consecutive correct spaced reviews) · **Maintenance** (Solid, in the long-interval hold pattern)

Error buckets: **(a)** prerequisite gap · **(b)** current-concept misunderstanding · **(c)** execution slip *(mode-specific — see the mode file)* · **(d)** novel case

Don't upgrade a mastery rating from a single correct answer; require it to hold across a session or a spaced recheck first.
